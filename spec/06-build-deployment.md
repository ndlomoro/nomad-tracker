# NomadTracker — Build & Deployment

## Project Structure

```
nomad-tracker/
├── generate_xcodeproj.py    # Regenerates NomadTracker.xcodeproj/project.pbxproj
├── project.yml              # XcodeGen-format intent doc (not used for actual builds)
├── NomadTracker.xcodeproj/  # Tracked in git; regenerate with generate_xcodeproj.py
├── NomadTracker/            # Main app target
│   ├── App/                 # App entry point
│   ├── Data/                # Core Data stack + photos import
│   ├── Models/              # Swift domain models (Stay, Country, …)
│   ├── Resources/           # visa_database.json, photos_import.json
│   ├── ViewModel/           # StayStore, VisaCalculator
│   └── Views/               # SwiftUI views
├── NomadTrackerWidget/      # WidgetKit extension target
├── NomadTrackerIntents/     # Siri/Shortcuts intents target
├── Shared/                  # Code compiled into all three targets
│   └── SharedStayData.swift # Widget data structs + file-based persistence
└── Data/                    # Source data files (not bundled directly)
    ├── visa_database.json
    └── photos_import.json
```

## Build System

The project file is managed by `generate_xcodeproj.py`, a Python script that writes `project.pbxproj` directly. Run it after adding or removing Swift source files, or when changing build settings.

```bash
python3 generate_xcodeproj.py
```

**Do not** run `xcodegen generate` — `project.yml` is kept for documentation only and is not kept in sync with the generated project.

## Targets

| Target | SDK | Deployment | Purpose |
|--------|-----|------------|---------|
| NomadTracker | macosx | 14.0 | Main app |
| NomadTrackerWidget | macosx | 14.0 | Desktop widget extension |
| NomadTrackerIntents | macosx | 14.0 | Siri/Shortcuts intents |

## Build Commands

```bash
# Open in Xcode (primary workflow)
open NomadTracker.xcodeproj

# Build from command line
xcodebuild -project NomadTracker.xcodeproj \
  -scheme NomadTracker \
  -configuration Debug \
  build

# Build for macOS explicitly
xcodebuild -project NomadTracker.xcodeproj \
  -scheme NomadTracker \
  -destination 'platform=macOS' \
  build
```

## Code Signing

Both targets use ad-hoc signing (`CODE_SIGN_IDENTITY = "-"`), which works without an Apple Developer Program account. Neither target uses entitlements that require provisioning profiles.

> See `spec/08-macos-local-build.md` for the full local setup including widget embedding details.

## Data Files

| File | Location | Purpose |
|------|----------|---------|
| `visa_database.json` | `NomadTracker/Resources/` | 195+ countries with visa rules; bundled as app resource |
| `photos_import.json` | `NomadTracker/Resources/` | Pre-generated travel history from Apple Photos GPS |

`photos_import.json` is generated by `Scripts/import_photos_data.py` from the user's Apple Photos library and is NOT regenerated automatically — it is checked in as a static snapshot.

## Core Data

The Core Data model is created programmatically in `PersistenceController.createModel()`. There is no `.xcdatamodeld` file. This avoids Xcode 26 model format incompatibilities.

Do not add a `.xcdatamodeld` file. Extend `createModel()` instead.

## No Automated Tests

The test target exists in the project file but contains no test cases. Manual testing via Xcode is the current workflow.
